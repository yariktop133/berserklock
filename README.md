# BerserkLock ⚔️🩸

Нативный твик экрана блокировки для **iOS 15.8.7** (iPhone SE 1st Gen) под Rootless джейлбрейк **Dopamine** с установкой через **Sileo**.

---

## 🗡️ Особенности

- **Часы в стилистике «Берсерк»:**
  - Отрисовка культового знака **«Клеймо Жертвы» (Brand of Sacrifice)** через векторные контуры `UIBezierPath`.
  - Зловещая пульсирующая анимация свечения («биение сердца Затмения») с переливом кроваво-красного оттенка.
  - Кастомные цифровые часы и локализованная дата с неоновым багровым ореолом.
  - Девиз Затмения: *«STRUGGLE, CONTEND, WRIGGLE»*.
  - Аккуратная замена стоковых часов iOS 15 без конфликтов с системным интерфейсом.
- **Процедурные красные молнии при свайпе:**
  - Генерация ветвящихся фрактальных разрядов (алгоритм Midpoint Displacement) прямо по траектории пальца.
  - Двухслойный рендеринг: яркий горячий сердечник + объемное кровавое свечение + микро-искры.
  - **Тактильный отклик (Taptic Engine):** легкая вибрация при генерации разрядов.
  - Прозрачность для системы: свайпы не блокируют разблокировку экрана, открытие камеры и центр уведомлений.
- **Оптимизация под iPhone SE (чип A9):**
  - Автоматическая остановка таймеров и анимаций при засыпании экрана для сохранения 100% ресурса аккумулятора.
  - Автоматическая очистка слоев анимации из оперативной памяти.

---

## 📱 Совместимость

- **Устройство:** iPhone SE (1-е поколение, 2016, экран 4" / 320x568 pt) и любые другие iPhone на iOS 15.
- **Версия iOS:** iOS 15.0 – 15.8.7+.
- **Джейлбрейк:** Dopamine (Rootless, архитектура `iphoneos-arm64`).
- **Менеджер пакетов:** Sileo, Zebra.

## 🛠️ Способы сборки `.deb` пакета

### Способ 1: Сборка в облаке через GitHub Actions (Самый простой, без настройки ПК)

1. Загрузите файлы этого проекта в свой репозиторий на GitHub.
2. Перейдите во вкладку **Actions** в вашем репозитории.
3. Запустится workflow **Build BerserkLock** (или запустите вручную через кнопку `Run workflow`).
4. После завершения сборки скачайте готовый артефакт `BerserkLock-iOS15-Rootless` с расширением `.deb`.

---

### Способ 2: Сборка локально через WSL / Linux / macOS

1. Откройте терминал WSL / Ubuntu.
2. Установите Theos (если еще не установлен):
   ```bash
   bash -c "$(curl -fsSL https://raw.githubusercontent.com/theos/theos/master/bin/install-theos)"
   ```
3. Перейдите в каталог проекта:
   ```bash
   cd /mnt/c/projects/tweaks
   ```
4. Запустите сборку:
   ```bash
   chmod +x build.sh
   ./build.sh
   ```
   Или напрямую:
   ```bash
   make package FINALPACKAGE=1 THEOS_PACKAGE_SCHEME=rootless
   ```
5. Готовый `.deb` файл появится в папке `packages/`.

---

## 📲 Установка на iPhone через Sileo

1. Передайте собранный `.deb` файл на iPhone (через AirDrop, Telegram, iCloud Drive или локальный веб-сервер).
2. Откройте `.deb` файл на iPhone через **Filza File Manager** или поделитесь им в **Sileo**.
3. В Sileo нажмите **«Установить»** (Get / Install).
4. Выполните быстрый **Respring** (перезапуск SpringBoard).
5. Заблокируйте и включите экран iPhone SE — наслаждайтесь эстетикой Берсерка и красными молниями при свайпе!
